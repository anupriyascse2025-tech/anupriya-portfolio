## 🛠️ How to Run Locally

You can serve this portfolio using any standard local web server:

```bash
# Option 1: Python HTTP Server (already running on port 3000)
python -m http.server 3000

# Option 2: Node.js / npx serve
npx serve .
```

Open your browser at `http://localhost:3000`.

## 🌐 1-Click Free Permanent Hosting Options

### 1. GitHub Pages (Free, Fast, Custom Domain)
1. Create a repository on your GitHub account (e.g. `anupriya-portfolio`).
2. Run:
   ```bash
   git remote add origin https://github.com/<your-username>/anupriya-portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. Go to **Settings > Pages > Source > Deploy from a branch (main)**.
4. Your site is live at `https://<your-username>.github.io/anupriya-portfolio`!

### 2. Vercel / Netlify
- Drag and drop the `anupriya-portfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on Vercel for instant free global CDN hosting.
